# APEX // APPS - safety classification for preinstalled packages.
# <pattern> <level> <note>
# level: safe = removing it only loses that feature
#        care = something visible may stop working
#        keep = system depends on it, APEX refuses to touch it
# Patterns match a whole package name, or a prefix when they end with *.
# Longer patterns win over shorter ones.
